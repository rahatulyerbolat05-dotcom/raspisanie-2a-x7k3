# Расписание 2 «Ә»

Веб-приложение с расписанием: какой урок идёт сейчас, какой следующий, перемены, календарь.
Обычная статическая страница, ничего устанавливать не нужно.

- `index.html` — вёрстка и логика (трогать только ради дизайна).
- `schedule-data.js` — **единственный файл, который меняется при обновлении расписания**
  (уроки, звонки, каникулы, объявления, за сколько минут напоминать). Подсказки — в комментариях внутри файла.
- `sw.js` — крошечный service worker, нужен только чтобы телефон мог показывать уведомления. Ничего не кэширует.

После правки `schedule-data.js` поменяй номер в `index.html` (`schedule-data.js?v=2` → `?v=3`),
чтобы телефоны не брали старую копию из кэша.

## Напоминание за час до уроков

1. **Календарь телефона (надёжный способ).** Кнопка «Добавить напоминания в календарь телефона» скачивает
   `raspisanie.ics`: по событию на каждый учебный день с сигналом за 60 минут до первого урока.
   После импорта телефон напоминает сам, даже когда приложение закрыто. Каникулы, события и выходные пропускаются.
   Если расписание изменилось, скачай файл заново (у событий постоянные UID).
2. **Уведомление в браузере.** Переключатель в приложении. Сработает только пока приложение открыто:
   у статического сайта без сервера нет способа разбудить закрытую страницу.

Время напоминания: `REMIND_BEFORE_MIN` в `schedule-data.js` (по умолчанию 60).
