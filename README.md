# Расписание 2 «Ә»

Веб-приложение с расписанием: какой урок идёт сейчас, какой следующий, перемены, календарь.
Обычная статическая страница, ничего устанавливать не нужно.

- `index.html` — вёрстка и логика (трогать только ради дизайна).
- `schedule-data.js` — **единственный файл, который меняется при обновлении расписания**
  (уроки, звонки, каникулы, объявления). Подсказки — в комментариях внутри файла.

После правки `schedule-data.js` поменяй номер в `index.html` (`schedule-data.js?v=1` → `?v=2`),
чтобы телефоны не брали старую копию из кэша.
